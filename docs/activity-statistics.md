# 应用活跃统计

此功能用于了解 Tokei 的活跃安装规模和版本分布，默认开启，可在「设置 → 隐私与额度 → 应用活跃统计」关闭。已明确关闭的设置会在升级后继续保留。关闭不影响用量统计、额度查询、更新或设备同步。

## 发送内容

应用每次启动时检查开关，启用时仅尝试上报一次。没有定时上报，失败或取消后本次运行不重试，无补发队列，不阻塞界面。同一天再次启动会再次上报，但后台按日期和安装 ID 去重。运行中关闭立即停止后续发送并取消在途请求，重新开启于下次启动生效。

```json
{
  "installation_id": "随机 UUID v4",
  "app_version": "1.0.39",
  "os_name": "macOS",
  "os_version": "26.0"
}
```

服务端以自己的接收时间记录首次及最近活跃时间，并保存本次连接的来源 IP，覆盖之前的 IP，不维护 IP 变更历史。使用代理或 VPN 时，来源 IP 通常是其出口地址。服务端同时按 UTC 日期和安装 ID 去重记录活跃日期，以便统计趋势。

不上传账号、邮箱、设备名称、硬件序列号、项目路径、对话、API Key、Token、成本、模型用量或额度。请求不携带客户端密钥或 Cookie，也不跟随重定向。

## 安装 ID 与隐私

ID 在首次上报前生成，独立保存在 `~/Library/Application Support/Tokei/Telemetry/state.json`，用于识别同一安装，不基于硬件信息生成，不写入 Tokei 设备同步目录，并标记为不参与系统备份。它仍可关联同一安装的多次活跃记录，因此本功能属于可关闭的遥测，不能称为完全匿名。

Windows 使用系统本地应用数据目录中的 `com.tokei.windows/Telemetry/state.json` 保存安装 ID。上报的 `os_name` 为 `Windows`，`os_version` 使用系统内核的主次版本，例如 `10.0`。统计进程使用安装包内嵌 Python，主窗口每次启动仅启动一次；关闭开关会终止该进程，重新开启在下次启动生效。快捷面板不会另行上报。

同一人使用多台电脑会计算为多个安装；复制状态文件会合并安装，删除该文件会产生新 ID。首次出现表示首次参与统计，不能据此推断实际安装日期。活跃日期仅代表成功上报的启动日期；应用跨天持续运行不会产生新的活跃记录，因此日／周／月指标统计的是这些窗口内启动过的安装。关闭统计或使用旧版本的安装不会计入。

关闭后取消正在进行的请求并停止后续上报；已经到达服务端的请求无法撤回，已保存的统计记录不会自动删除。源 IP 仅在最近安装记录中保存，历史每日记录不包含 IP；平台备份可能暂时保留旧值。

## 开源范围

本仓库只包含客户端逻辑、测试和上述数据协议。上报地址公开可见，客户端没有任何后台管理凭据。服务端、运营页面、部署配置与数据库迁移位于独立私有项目。后台查询必须经过认证，公开上报接口会校验字段并限流。

本功能随包含这些改动的新版本生效；官网隐私文案应与该版本一同发布。
