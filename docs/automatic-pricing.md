# 自动价格核对

Mac 和 Windows 在完整用量采集后启动独立的后台核价进程，通常每 24 小时一次。缺少精确价格的新模型会触发提前检查，两次检查至少间隔 5 分钟；网络或解析失败后间隔 1 小时再试。连续运行时也会检查，无须重启应用或点击「全量更新」。本地首屏预览不会发起核价，也不会等待下载。

当前来源：

- OpenRouter 公开模型目录覆盖各厂商模型。
- OpenAI 官方公开价格页：<https://developers.openai.com/api/docs/pricing>。读取 Standard 表，区分输入、输出、缓存读、30 分钟缓存写以及长上下文档位，排除 Batch、Fast 和 Ultrafast 表。

OpenAI 的核实结果优先于目录价格与内置兜底价。其他厂商目前按公开目录更新，尚未逐一接入各自官网。没有精确价格时继续使用已有估算；Codex 模型明细会标明参照模型。

`~/.tokei/pricing_official.json` 保存核实的价格、来源与核实时间；`pricing_update_state.json` 保存检查时间、排队状态和失败来源。Windows 使用应用现有状态目录。更新只对固定公开地址发送 GET 请求，不附带用户的模型名、Token 记录、对话或凭据。缺价标记仅以摘要保存在本机。

已在 `pricing_overrides.json` 中自定义的值保持优先。与应用内置值完全相同的条目按安装默认值处理，可以由新核实的官方价更新。旧模型的最后有效价格继续保留；页面结构变化或网络失败不会写入零价，不清空日志或历史。新价格与长上下文规则参与价格指纹，缓存事件会按新价重算费用。

如需停用自动核对，可在现有 `config.json` 中设置 `"auto_pricing_enabled": false`，或在启动应用的环境里设置 `TOKEI_AUTO_PRICING=0`。手动「全量更新」仍可使用，会同时尝试两个来源。
