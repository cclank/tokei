# v1.0.50

- 新增豆包工作（Doubao Work）已缓存 Agent 会话统计，支持 macOS / Windows 卡片、时间范围、历史保留和分享；多设备同步按哈希会话标识去重。
- 新增默认关闭的豆包工作额度连接试验功能。主动连接并登录豆包官网后，可读取当前时段与 7 天额度及重置时间；登录状态由 Tokei 自己的网站会话保留。后台每 5 分钟尝试刷新，失败时不自动打开登录窗口，保留上次有效额度并标注待刷新。
- 豆包会话统计与账号额度分别展示，额度不随所选统计日期重复累计，也不跨设备相加。尚无可靠的 Token 数量或生成耗时，继续保持这些指标缺失。
- 包含 Grok Bot 授权保留和后台无交互读取修复：复用已授权的持久助手，保护历史授权标记；无法安全读取时静默停止，主动授权时才允许系统交互。
- 优化单工具弹窗的紧凑布局和箭头外观，保留既有弹窗定位修复。

验证边界：豆包额度连接尚缺真实账号登录后的端到端验收，以及 Windows WebView2 的登录和重启保留实机验证，当前作为可选试验功能发布。钥匙串兼容检查覆盖 CI 提供的 macOS 15、15 Intel 和 26；不代表已覆盖所有旧系统。

安装包：macOS 通用 DMG 包含 Apple Silicon 和 Intel；Windows x64 安装包内置 Python。
