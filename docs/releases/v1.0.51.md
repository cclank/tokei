# v1.0.51

- 修复登录项命令输出较多时可能发生的管道死锁，避免启动设置卡住。
- 优化 macOS 弹窗顶部背景与箭头的衔接，保留现有卡片锚点和定位逻辑。
- 修复 Copilot 每日费用在同步快照中的遗漏，支持零费用用量和多工具费用汇总，避免同步中断。
- 菜单栏样式改为两列预览选项，信息量选择器在空间不足时使用菜单，避免设置卡片溢出；保留原有样式配置及无障碍分组标签。
- 离屏设置预览跳过真实 Provider 凭据和同步初始化，避免预览过程访问用户凭据。

沿用 v1.0.50 的 Grok Bot 历史授权保留和后台无交互读取机制。升级不会主动替换已授权的持久助手；系统授权窗口仅在用户主动授权时出现。

安装包：macOS 通用 DMG 包含 Apple Silicon 和 Intel；Windows x64 安装包内置 Python。
