# v1.0.52

- Claude Code 补采会话结算中的 Haiku 等辅助模型用量，并扣除已计入的消息和子代理用量。费用按搜索次数、缓存档位和长提示规则计算。
- Claude Code 卡片的「按模型」把搜索与网页读取标记、Token 和费用放在同一行。日志提供模型归属时才显示对应次数。
- 修复 macOS 浅色菜单栏的文字对比度，统一处理分隔符和过期读数。
- 新增 Linux amd64 桌面安装包。支持通过系统 `zstd` 读取 Codex 压缩归档，Provider 密钥使用 Secret Service。

macOS 通用 DMG 支持 Apple Silicon 和 Intel。Windows x64 安装包内置 Python。Linux 提供 `.deb`。
