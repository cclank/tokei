- 菜单栏可切换额度百分比或 Token 用量，支持今日和本周期，默认分别显示 Claude、Codex。单用量模式显示用量最大的工具，悬停可查看精确数值。Windows 托盘悬停提示同步支持。

- 修正 Antigravity Orchestrator、Worker 的模型映射与价格参照，分开展示输出和推理用量；补充 Claude Fable 5.2 及 Fast 模式计价。

- 合入社区修复 [#150](https://github.com/cclank/tokei/pull/150)、[#153](https://github.com/cclank/tokei/pull/153)：直接读取 DeepSeek Harness 压缩会话，修复工具退出后 SQLite WAL 数据库读取失败、卡片消失的问题。
