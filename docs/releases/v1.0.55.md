# v1.0.55

## 优化

- 提升 macOS 卡片页的滚动流畅度。多设备数据合并和额度历史保存交给后台处理，滚动时用量仍会继续刷新。
- 减少卡片重复排版，避免滚过光标时整张卡片放大。

## Improvements

- Scrolling the macOS usage cards stays smoother during refreshes. Tokei now merges device usage and saves quota history in the background.
- Cards reuse row measurements and stay in place as they scroll under the pointer.
