# v1.0.56

## 新增

- macOS 菜单栏可以选择显示 Antigravity 剩余额度。
- 支持统计 T3 Code 中的 Antigravity 会话用量，按会话去重并保留历史统计。

## 修正

- Claude Code 缓存额度恢复正常条色，并显示上次读取时间。额度窗口重置后显示「已重置」。
- 修正 Claude Code 长上下文和跨文件续接会话的重复统计，保留已清理日志的历史用量。
- 兼容新版 Antigravity Hub 的本机额度服务。Hub 凭据仅用于已核验的本机端口，并留在内存中。
- 再次点击 macOS 菜单栏图标时可以正常收起面板。
- 价格更新结果跟随应用语言，macOS 多设备同步提示也随界面语言显示。

## Added

- Antigravity remaining quota is available as a macOS menu bar option.
- Collect Antigravity usage from T3 Code profiles, deduplicate sessions, and retain historical totals.

## Fixed

- Cached Claude Code quota bars keep their normal colors and show when the quota was last read. A reset window is marked as reset.
- Fixed duplicate Claude Code accounting for long-context and resumed sessions while preserving usage from deleted logs.
- Discover newer Antigravity Hub quota endpoints and keep Hub credentials in memory for verified loopback ports.
- Clicking the macOS menu bar icon a second time hides the panel.
- Price update results follow the app language. macOS sync messages are localized as well.
